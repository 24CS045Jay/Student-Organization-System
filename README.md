# ClubSphere —  Club Management & SaaS Platform

A modern, responsive Neo-Brutalist React prototype for multi-tenant college club and student organization management.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build
```

## 🎨 Design System
- **Color Palette:** Warm cream canvas (`#FDF8F0`), Sunflower yellow (`#FFD24C`), Bubblegum pink (`#FF70A6`), Mint seafoam (`#70E4A8`), Lavender (`#C8B6FF`), and Sky azure (`#74B9FF`).
- **Aesthetics:** 3px crisp black borders, hard unblurred drop shadows (`4px 4px 0px #121212`), rounded brutalist cards (`20px`), and rotated sticker badges.
- **Typography:** Space Grotesk, Archivo Black, Outfit.

## 🔑 Demo User Roles
Access any role via the **"⚡ Demo Roles"** top-bar button:
1. **Student / Member** (`student@tech.demo`) — Digital QR ID pass, event bookings, merch shop, orders, certificates.
2. **Volunteer** (`volunteer@tech.demo`) — Kanban task board, log service hours, expense reimbursement claims with receipt upload, leaderboard.
3. **Event Manager** (`events@tech.demo`) — Event CRUD, simulated door QR check-in camera scanner, attendance demographics, event P&L.
4. **Treasurer** (`treasurer@tech.demo`) — Treasury cash reserves, income sources, expense ledger, multi-stage reimbursement approval.
5. **Club Admin** (`admin@tech.demo`) — Club dashboard, member roster, inventory POS, campaigns, AI Copilot, audit log.
6. **Platform Super Admin** (`root@clubsphere.demo`) — SaaS tenant hierarchy (University → College → Dept), subscription plans, module architecture.
